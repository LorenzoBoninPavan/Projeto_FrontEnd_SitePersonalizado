# Projeto Web: Gerenciamento de Personagens do jogo Saint Seiya Awakening

#Sobre o Projeto

Este projeto web de tema livre foi desenvolvido utilizando HTML e CSS, com foco na temática de um jogo. A aplicação foi idealizada para funcionar como um assistente pessoal de jogo, permitindo que o usuário organize seus personagens, acompanhe a evolução de suas habilidades e consulte dicas estratégicas sobre eles.

#Funcionalidade e Funcionamento

Como o projeto foca na estrutura e estilização (sem banco de dados relacional ou persistência avançada de backend), o fluxo simula uma experiência interativa e funcional de front-end.
1. Cadastro de Usuário: Uma interface para simular a criação de conta ou login, dando aspecto personalizado à sessão do jogador.
2. Navegação pelo Site: Páginas estruturas para transitar entre a central de personagens, telas de cadastro e seções de dicas.
3. Gerenciamento de Personagens: Um espaço dedicando onde o usuário pode adicionar novos personagens à lista pessoal.
4. Anotação de Upgrades e Dicas: Áreas visuais planejadas para registrar o nível de evolução das skills de cada personagem e exibir dicas úteis sobre o gameplay.

#Tecnologias Utilizados
HTML5: Estruturação semântica das páginas, formulários de cadastro e listagens.
CSS3: Estilização visual com temática gamer, organização de layouts (Flexbox/Grid) e responsividade básica.
Conceitos Aplicados: Criação de interfaces web multi-páginas ou em abas, design focado em experiência do usuário (UX/UI para jogos) e estruturação de formulários
